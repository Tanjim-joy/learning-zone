# 05-Interview-Prep

Classic programming-interview warm-ups (C# console apps).

| Folder | Problem |
|---|---|
| `Armstrong Number/` | Check if a number is an Armstrong number |
| `Calculator/` | Console calculator (switch: + - * / %) |
| `Factorial Number/` | Factorial via loop |
| `Fibonacci Series/` | Fibonacci sequence generator |
| `Palindrome Number/` | Palindrome check by digit-reversal |
| `Reverse Number/` | Reverse digits (note: leading zeros ignored) |
| `Star Pattern/` | 9 star/number patterns |
| `Swap Two Numbers/` | Swap using 3 variables and using 2 variables |
