## 🚦 How to use

1. Browse by topic folder above.
2. Inside `01-CSharp/` you'll find topic sub-folders (Basics, Loops, OOP, LINQ, …).
3. Each topic/project folder is a small console app — just one `Program.cs` build & run.
4. `Archive/` holds anything removed from the main structure — **do not delete** unless sure.

## 🔧 Notes for contributors / future-you

- Build artifacts (`bin/`, `obj/`, `.vs/`) are **git-ignored** — rebuild to regenerate.
- Prefer committing source only (`*.cs`, `*.csproj`, `*.sln`, `*.md`).
- Old root README (generic template) is preserved at `Archive/Old-README.md`.
