# 01-CSharp

C# language practice — everything from variables to async.

## Sub-folders

| Folder | What it contains | Project count |
|---|---:|---:|
| `Basics/` | variables, operators, input/output, decision (if/switch), strings, hello-world | 36 |
| `Loops/` | for / while / do-while / foreach examples | 12 |
| `Methods/` | method overloading, parameters | 2 |
| `OOP/` | class, inheritance, interface, abstract, generic, getters/setters, constructor, enum | 19 |
| `LINQ/` | `csharp-linq-practice` + Product + Evidance11 (grouping, joins) | 3 |
| `File-IO/` | text file reading, streams | 3 |
| `Async/` | async/await factorial demo | 1 |
| `SampleProjects/` | Game, Vehicle/EvidanceXm, EmployeeTable-class13, trainee | 4 |

## Build & run

Most folders are standalone .NET console projects:

```powershell
cd 01-CSharp\Basics\vari
dotnet run          # or open the folder in VS Code / Visual Studio
```

> ℹ️ Many of these are tiny classroom exercises with default `Program.cs` names. They are kept
> as learning history. Duplicates and broken samples were moved to `../Archive/`.
